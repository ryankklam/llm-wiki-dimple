# Claude Code

## 定义
Claude Code 是 Anthropic 推出的 AI 编程 IDE，允许用户通过自然语言与 Claude 协作构建软件项目。

## 关键信息

### Claude Code 的核心功能
- 支持安装和使用 Skill 来扩展能力
- 可通过 Skill Creator 工具创建自定义 Skill
- AI 负责执行和生成代码，用户负责决策和判断

### Skill 创建流程
1. 安装 Skill Creator 工具
2. 告诉 AI "我要创建一个技能"
3. 回答 AI 的问题（需求、来源、内容格式等）
4. AI 自动生成 Skill 文件
5. 测试调试后分享
