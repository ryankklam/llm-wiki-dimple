# Execution Layer（执行层）

## 定义

执行层是 Harness Engineering 四层架构的第二层，解决 LLM 只能生成文字、无法操控外部世界的问题。赋予模型实际执行能力，如 bash 执行、代码运行、浏览器操控、API 调用等。

## 解决的问题

LLM 的结构性缺陷之一：**无法操控外部世界**
- 只能生成文字
- 无法执行实际操作
- 只能"讲"不能"做"

## 核心能力

| 能力 | 说明 |
|------|------|
| Bash 执行 | 运行命令行指令 |
| 代码运行 | 执行代码片段 |
| 浏览器操控 | 操作网页浏览器 |
| API 调用 | 调用外部服务接口 |

## 沙箱环境

执行层在**沙箱环境**中运行，具有以下特点：
- **试错成本为 0**：Agent 可以大胆尝试
- **隔离工作区**：每个任务独立执行
- **改坏直接丢弃**：不影响主分支

## 效果

让模型从：
> "我只是给您去讲一些话"
变成：
> "我去做这个事情"
