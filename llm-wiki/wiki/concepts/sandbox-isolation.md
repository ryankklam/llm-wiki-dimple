# Sandbox Isolation（沙箱隔离）

## 定义

沙箱隔离是 Harness Engineering 的设计模式之一。每个 Agent 的任务在独立的工作区里执行，互不干扰，改坏了直接丢弃。这让 Agent 可以大胆的试错，失败的成本接近于零。

## 核心特点

| 特点 | 说明 |
|------|------|
| 独立工作区 | 每个任务在隔离环境中执行 |
| 互不干扰 | 一个任务的失败不影响其他任务 |
| 改坏丢弃 | 不正确的结果直接丢弃，不影响主分支 |

## 解决的问题

- **试错成本高**：Agent 不敢尝试新方法
- **风险隔离**：局部失败不影响整体系统
- **大胆创新**：鼓励 Agent 大胆尝试

## 效果

> 这让 Agent 可以大胆的试错，失败的成本接近于零。
