# Feedback Layer（反馈层）

## 定义

反馈层是 Harness Engineering 四层架构的核心层，解决 LLM 输出不可靠的问题。通过测试、Linter、CI 流水线等工具，构成对模型产出的确定性验证机制。

## 解决的问题

LLM 的结构性缺陷之一：**输出概率性**
- 同样的输入可能产生不同输出
- 无法保证哪一次是对的
- 输出质量不稳定

## 核心机制

### 反馈回路
```
模型生成代码 → 测试立刻跑一遍 → 不通过则自动打回重试 → 通过才进入下一步
```

### 工具链

| 工具 | 作用 |
|------|------|
| 测试 | 验证功能正确性 |
| Linter | 检查代码规范 |
| CI 流水线 | 自动化验证流程 |

### 速度提升
- **人工 review**：小时级
- **自动化反馈**：秒级

## 不对称性原理

反馈层可行的根本原因：**代码生成是概率性的，但验证是确定性的**

- 编辑器不会因为你今天心情好就放过语法错误
- 测试不会因为你的态度端正就假装通过
- 这种确定性让反馈回路完全自动化

## 核心原则

> 你不需要模型每次都对，你只需要有足够好的验证手段就够了。
