## 完整文本

怎么从头去写一个你自己的 skill？今天我们就来做这样一件很多人一直想做，但是不知道怎么去开始的事情，就是去写这个 skill。

你看你装了 superpowers，装了 front end design，装了各种别人做好的 skill，用的确实很爽，对不对？但是你们想过，你工作里那些每天都在重复的事情，是不是也可以去打包成一个 skill？答案呢，是可以的，而且比你想象的要简单的多。

OK，首先我们先搞清楚一个 skill 到底是长的什么样。一个 skill 的本质就是一个文件夹，里面最核心的是 skill.md 的文档。这个 skill.md 的文件相当于是 skill 的一个大脑，里面写了两部分内容：上面是原数据，告诉 AI 我是谁、我能干什么；下面是操作指南，告诉 AI 我具体应该怎么去干。

除此之外，根据你的 skill 具体的需求，AI 还会自动的帮你去匹配相应的文件夹。比如说如果你的 skill 需要去独立执行的脚本，就会有 scripts文件夹；如果需要放模板文件、配置实例等参考材料，就会有 reference 文件夹。一个 skill 的本质就是这样一组文件，AI 像操作电脑一样去调整它，整个过程都是由 AI 去引导的，你负责做决策和判断就可以。

OK，那搞清楚结构以后，我们去走一遍从零到可用的一个完整流程，总共是有六步。

**第一步，你要去想清楚你要解决是什么问题。** 这一步最关键，很多人一上来就写啊，写了一半发现自己都没想清楚这个 skill 到底是做什么。你可以问自己一个问题：我这个工作哪个环节是重复超过三次的？那这个环节呢，就值得去变成这个 skill。你看我之前做每日 AI 新闻速递，每天都要去好几个网站去爬这个新闻，去翻译、去整理、去排版，这个流程呢非常重复性，我做三天就受不了了，那这个就是我认为的一个完美的 skill 场景。OK 好。

**那到第二步，就是告诉 AI 你要去创建这个技能。** 那你可以在对话框里面去说："帮我创建一个新的技能"，或者说"我要做一个棒棒的 skill"。那前提条件呢，就是如果你的 Claude Code 已经安装好了 Skill Creator 这个工具，你可以直接去说；如果没有的话呢，你现在对话框里面说"帮我去安装 Skill Creator"，那 AI 呢会自动的去为你安装。那安装完成以后，你就可以去告诉 AI 你要去创建什么样的技能。

**好，那到第三步，就是去回答 AI 给你的问题。** 接下来呢 AI 就会像产品经理一样去问你细节了，你只需要一一回答就可以了。AI 会先问你一个基本的需求：你希望从哪些网站去抓取 AI 新闻？生成的日报包含哪些内容？要标题、要摘要、还要有链接吗？以及日报的输出格式是什么样的？包括日报文件保存在哪个位置？你回答完这一轮以后呢，AI 会基于你的需求进行更深层次的提问，比如你需要每天抓取多少条的新闻？需不需要自动翻译成中文？提到的自定义网站会是哪些？通过这样一个多人对话，AI 就会逐步的完善你的 description，确保生成的 skill 能够去精准匹配你的需求。

那为什么 description 这么重要？因为 AI 就是靠这段描述来判断，用户说的这个需求跟我这个 skill 是匹配的。你的 description 写的越精准，那 AI 匹配的就会越准。这整个机制就叫做按需加载。AI 不是去把几百个 skill 全部去读进来，他会先看原数据目录，发现匹配了才会去读详细内容。所以这段描述相当于图书馆的目录卡片，写的好 AI 才能匹配的上你。

OK，那到第四步，就是 AI 自动的去生成这个技能文件。这一步完全就是 AI 在做，你只需要去等几秒钟，AI 就会根据你的回答自动去生成这样的一个 skill 文件。你可以看到 AI 生成的文件包含了完整的原数据和详细的操作指南。

OK，**第五步，就是去做测试去做调试了。** 那技能创建好以后，你可以直接试着用一下。你看这就是我最后制作出来的 dailyai news 的样子，你可以看到日报包含了标题、包含了摘要、包含了链接，还有自动翻译的中文内容。我只要说出触发词，看 AI 是不是自动调用了我的 skill，执行结果对不对就 OK 了。那如果出问题呢？看 AI 的执行过程，找到偏差的地方去修改 .md 文件，再试一次，改个两三轮基本上就稳了。

OK，**那到第六步，也是我觉得最最关键的一步：你要把你的 skill 给分享出去。** 如果你觉得你的 skill 别人也可以用，可以去铺到 GitHub 或者投到 skillsmp 这个平台。那 skill 呢，也不是写完就完了的，他是会自己长大的。比如说你用着用着发现，哎我可能需要再去调整一下，那你随时去改 .md 文件就行，改一次永久生效。

OK，所以呢，从零写一个 skill，核心呢就三件事情：**想清楚问题，告诉 AI 需求，测试调试迭代。** 没有任何代码门槛。所以我的建议就是，你现在去打开 Claude Code，想一个你每天都在重复的事情，花 20 分钟把它变成你的第一个 skill。

OK，那今天的分享就在这里。如果大家对 AI 的学习感兴趣呢，也欢迎去搜索匠学的 AI 学习圈，我们呢也有 2000 多位的星球朋友一起去学习 AI，包括我们也开设了好几期的实战打卡以及加密分享，感兴趣呢可以评论区留言。
